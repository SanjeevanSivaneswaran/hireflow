
# HireFlow

AI-powered Applicant Tracking System (ATS).

HireFlow helps recruiters manage candidates, job applications,
interviews and recruitment activities in one place.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL, Supabase
- ORM: SQLAlchemy
- Migrations: Alembic
- Resume extraction: PyMuPDF
- AI extraction: Google Gemini
- File storage: Supabase Storage

## Main Features

- AI-powered PDF resume extraction
- Candidate profile review and correction
- Candidate project management
- Job management
- Application tracking
- Kanban recruitment pipeline
- Application activity history
- Interview scheduling
- CSV export

## Project Structure

- backend/ - FastAPI application
- frontend/ - React application
